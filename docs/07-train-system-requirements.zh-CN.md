# 0.4 列车系统设计与 Use cases

本轮问题：检查栏产生空行；大车站未在建筑菜单出现；轨道仅正交；缺少停站时间设置、路线方向预览、多站点与站间货运。

## 设计规则与修改意见

1. 检查栏只拼接非空行；大站明确声明 Misc 建造分类和 3×3 尺寸，使用运行时建筑设计器列表验收，而非仅直接生成建筑。
2. 轨道支持八方向。斜向每格 4 ticks，正交 3 ticks。相邻格的正交轨道优先，避免现有直角和并排轨道被斜向捷径意外连通；斜向段额外检查两侧格障碍，不能切穿墙角。通过原生 DrawStyle 接口实现自定义斜向铺设样式，并绘制匹配的斜向钢轨和车体朝向。
3. 一条路线为 2–8 个不同、有序车站；列车沿顺序逐站停靠，到末站折返，不是环线。每个连通轨道网仍只允许一个自动服务。相邻站之间路径不能穿过已指定的其他停站，整条路径不能重复格子，以避免顺序歧义和自交调度问题。
4. 玩家通过路线编辑窗口添加、删除、调整站序，设置各站停留 0.5–30 游戏秒（30–1800 ticks），默认 90 ticks。编辑时显示地图路径、箭头、起点/终点及站序。确认时再次校验连接和网络占用。修改现有路线会释放乘客，并要求列车当前位置仍在新路径上。
5. 乘客可在任意停站之间乘车。只搭乘朝目标方向的车；中途站下车，满员排队，原工作和携带物保留。候车估算包含中途停靠和每段速度。
6. 货运采用明确订单：车站选择货运目的站，玩家令殖民者装载附近货物到该站。货物首先交给站台队列，列车停靠时装入真实容器，到目的站卸在附近可放置格。每车最多八个货物批次；不自动拿走附近库存，也不抢占乘客座位。断轨或暂停时保留车载货物；目的站被拆、撤销路线或列车损毁时将货物安全放回地图；卸货失败时保留货物稍后重试。
7. 路线、每站停靠、待运/车载货物及目的站均可存档；兼容 0.2/0.3。保持无材料、电力、燃料要求，现有原创占位贴图继续使用。

## Use cases 与验收

| 场景 | 验收 |
|---|---|
| 无路线车站被选中 | 检查文字没有空行，3×3 站出现在正常建筑列表 |
| 铺斜向线 | 拖拽产生连续斜向格；钢轨、列车和乘客沿斜段运行，无穿墙角 |
| 选择/编辑路线 | 地图有有向路径及编号站点；不连通、重站、自交等明确拒绝 |
| 修改停站时间 | 30/90/1800 ticks 可设置并生效，保存加载保留 |
| A-B-C 往返 | 列车逐站停靠；乘客 A→B、B→C、C→A 可正确上下车 |
| 货物 A→C | 殖民者实际拾取和交付，车载容器持有真实货物，经过 B 不卸，到 C 卸出 |
| 货物中断/读档 | 数量守恒，取消、拆除与加载不丢失、不复制 |
| 多乘客/旧版本 | 四座和队列保留，原两站及旧存档仍可运行 |

## 实施顺序

先修复检查栏和菜单，再升级轨道邻接/段耗时，随后多站时刻与乘客、路线编辑和地图预览，最后货运容器/任务和存档恢复。纯逻辑覆盖路径与时刻；实际引擎覆盖菜单、文本、列车、中间站、货物数量及加载，图形运行确认可见标记。

补充通行规则：轻量轨道车与地面 Pawn 共享可通行格，不撞伤行人，不因静止角色占格永久停运。墙体、门、断轨、迷雾等物理与安全限制仍有效。货物卸出后交给原版搬运与堆叠规则处理。
