在一张殖民地地图内，用铁路连接住宅区、农场、矿区和仓库。殖民者在合适的长途工作中自行到站候车、乘车，下车后继续原任务；自动列车还可以在无人乘坐时运输仓库库存。

当前是可以游玩的早期版本。核心运输和在途存档已实机验证，素材、平衡、交互和兼容性仍在开发。

## 主要功能

- 玩家人类殖民者自动通勤，携带中的资源随人保留。
- 每路线一辆常驻列车，**四客位、12 个真实货物堆栈槽**。
- 普通列车载客并运输人工交付货物；自动列车额外收集仓库库存，可设为客货两用或货运专列。两种均无需司机。
- 可旋转的单、双、四站台客运站和货运仓库。
- **2–16 站**往返／实际闭合环线，名称、颜色、地图方向箭头和具体站台选择。
- 底部“轨道”标签页统一管理，支持编辑、搜索、定位、暂停与撤销。
- 直接输入停站时间或启用自动停站；殖民者提供“乘车诊断”。
- 默认库存目的站与分类发货规则，满仓或拒收时留车重试并发出不暂停提示。
- 直线／斜向轨道、双轨模块及金属单／双轨自动门。
- 车载实际货物图标、数量、目的站台和乘客名单。

## 依赖与安装

需要 **RimWorld 1.7** 和 [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077) 的 1.7 程序集。Harmony 在 Local Rail 之前加载。无 DLC 或额外载具框架依赖，包含中文和英文界面。

当前测试环境为 Windows 上的 **1.7.4977 rev1248 / Waylith CLR 10.0.10**。

发行包解压后，将 `LocalRail` 文件夹放入游戏的 `Mods/` 目录，在游戏中启用 Harmony 与 Local Rail，完全重启游戏。源码仓库需要先构建，再安装 `Mod/LocalRail`。构建生成的 ZIP 位于 `dist/`，此目录不纳入 Git。

`install.ps1` 是首次安装辅助脚本，遇到已存在的 LocalRail 目录会停止，避免直接覆盖。

## 快速开始

1. 在“杂项”建造至少两个车站，用轨道连接具体站台的端口。车站与列车门自带轨道，不要在占地内部重复铺设。
2. 打开“轨道”管理页，创建路线，选择停站顺序、具体站台、列车类型、名称和颜色。环线需要末站返回首站的实际连接；往返线允许回走本路线轨段。
3. 确认后，在设置中启用自动乘车与偏好列车。符合条件的非征召殖民者会自行乘车；接驳范围默认 80 格，可调整。继续步行时可用“乘车诊断”查看原因。
4. 无人货运请选择自动列车，在发货仓库设置“库存默认目的站”；按物品分配不同目的地时添加发货规则。殖民者通过原版搬运送入资源，列车到站自行装载。
5. 到货遵守目的仓库的筛选与容量，满仓或拒收时留车下次重试；已到货物默认不再自动发出，随后可搬往合适的普通储存区。

## 当前范围与限制

轨道、车站与仓库目前不消耗建造资源，但仍需施工；金属门消耗材料。暂不需要电力、燃料或研究，后续可能调整平衡。

每路线一车，不同路线不能共用轨道格；多站台分别接轨，站台之间不会自动互通。暂不支持世界地图铁路、自动跨线换乘、共享轨道信号、会车或同路线多车。

自动乘车限于受支持工作的移动阶段。征召、倒地、精神状态、离图任务和搬运活体 Pawn 不自动乘车；接驳、候车或安全条件不合适时仍会步行。宽车体完整碰撞尚未实现，列车门用于水平／垂直通道；复杂多环路网的部分站序可能被当前路径选择拒绝。

主要功能在 Core＋Harmony 配置中验证，其他工作、寻路、载具模组和整合包尚未全面测试。

## 构建与验证

项目目标为 `net10.0`，需要 [.NET 10 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)、本机 RimWorld 1.7 和 Harmony 1.7。现有脚本使用 Windows PowerShell。从仓库根目录运行，按安装位置修改路径：

```powershell
.\build.ps1 -Test `
  -RimWorldDir 'D:\SteamLibrary\steamapps\common\RimWorld' `
  -HarmonyPath 'D:\SteamLibrary\steamapps\workshop\content\294100\2009463077\1.7\Assemblies\0Harmony.dll'
```

脚本优先使用 `.tools/dotnet/dotnet.exe`，否则使用 PATH 中的 `dotnet`。官方程序集和 Harmony 来自本机安装，无 NuGet 包依赖。输出 DLL 到 `Mod/LocalRail/Assemblies/`，生成 ZIP 到 `dist/`。官方程序集、Harmony DLL、反编译代码及本地测试存档不应随本 Mod 分发。

0.10 验证记录含 **68 项生产逻辑检查、115 项实机检查**，涉及长距离接驳与普通门、无人货运、类型切换、在途读档、旧档迁移、折返、部分卸货、满仓和双轨门。它不代表所有模组兼容或大型殖民地性能保证。

[完整验收记录](21-passenger-access-train-types-validation.zh-CN.md) · [英文首页中的验证命令](../README.md#validation)

引擎脚本会更新本机安装的 Mod，并启动自己的隔离游戏进程；需要本机游戏、Steam／Harmony 可用。测试配置位于 `.local/`，不使用玩家存档。`.tools/`、`.local/`、`bin/`、`obj/` 和 `dist/` 均忽略。
