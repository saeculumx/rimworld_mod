# 0.9 旋转、车载货物与折返用例

1. 建造客站或货运仓库时，原版旋转键改变实际占地、轨道方向、储存格、预览、站台定位和两端接轨计算。编号随建筑旋转；旧建成车站按原东西向布局迁移，原编号与路线引用不变。
2. 列车实际装有货物时，车身显示原物品图标。相同类型和材质合并显示，最多六种图标；选中列车显示货物名称、数量及 12 格详情。装卸后的显示同步，不修改实际货物。
3. 收货中转仓库默认低优先级，原版搬运工可把到货送往普通储存区。有启用发货规则时自动切换为优先，用于集货；界面可以关闭自动管理并自选原版优先级。旧默认优先按用途迁移，其他自定义优先级保留。
   已卸货物不再被自动集货仓抢回，避免低优先级目的站到高优先级起站的搬运循环。到货标记在原版搬运与读档后保留；明确再次发货或手动仓储模式可以覆盖。
4. 往返路线允许同一列车在按站序行驶时重复经过本路线轨道格，例如 A→B→C 的 B→C 需要先回走 A→B 的一段。车站停靠、自动上车、货运方向和时刻表按行程索引计算，而非物理格的首次出现。
5. 验证重复格上的拓扑刷新和读档不会把列车跳回第一次经过的位置。不同路线仍需独立轨道，已有简单环线规则保留。
6. 实机复现同楼不同站台的折返路线；验证自动乘客双向乘车、旋转货站装卸后原版搬往普通储存区、车身图标和旧存档迁移。
