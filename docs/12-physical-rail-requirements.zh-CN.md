# 0.6 实体轨道、列车门与显示修正需求

本轮先以游戏行为明确需求，再实现和实机检查。沿用单地图、免费建设、自动乘车、常驻列车和 0.5 路线管理。

| 场景 | 设计与验收 |
|---|---|
| 四名乘客同时乘车，携带资源 | 车体为香草风格俯视占位；乘客分配不同座位，跟随车体插值与旋转，保留原版衣物/携物；下车恢复正常绘制。 |
| 轨道穿过泥土、砂地、石地和地板 | 路基、深色轨边、浅色钢轨提高可读性；材质边界不改变拓扑；细轨绘制避免倾斜面深度遮挡。 |
| 重建或拆除轨道/大站台 | 相邻轨段及跨地图网格区域重新绘制，转角连续；建筑菜单和预览继续可用。 |
| 轨道与树、墙、其他建筑相遇 | 轨道为可步行的实体建筑，有生命值、建造与拆除流程；不能与实体建筑叠放，施工必须先清除阻挡植物；允许按原版流程提前规划蓝图。 |
| 地形承载力不足 | 保留原版承载规则；水面需要先造可承载的桥，不用悬空连接掩盖问题。 |
| 封闭殖民地的布线和杂物 | 允许原版地下电缆穿过轨道与门；轨道不作为堆货格，装卸货在站外附近完成，避免大型物品遮住钢轨。 |
| 封闭走廊有列车门 | 新建筑继承原版门的房间、温度、寻路和开关行为，内置贯通轨道，无须门下叠铺轨道；殖民者可自行开门通行。 |
| 高速列车接近关闭的门 | 按轨段实际时长提前请求开门；开门未完成时车停在门前，乘客留在车内；不能穿过未开足的门。 |
| 车头过门后车尾仍在门内 | 保持门打开至整个视觉车体通过，随后由原版门关闭；空车也触发。 |
| 列车暂停、故障或读档时占门 | 门不能关到车体中；恢复运行后自动释放；拆门使路线断开，正常暂停。 |
| 禁用/禁止列车门通行 | 列车不强开被禁止的门，不卸乘客冒充通过；解除后自动重试。 |
| 斜向拖动 | 检查原生 DrawStyle 接口。优先使已有斜线样式容易发现；若可直接修正默认选择则修正，不编造引擎限制。 |

列车门首版为一格自动门，复用原版自动门素材和声音，保持香草建筑语言，无材料、电力或研究要求。支持水平与垂直轨道进出；禁止斜穿门角，不实现三格宽车辆碰撞或信号联锁。车体是视觉三格长车辆，路线和寻路仍以中心格计；提前开门和尾部保护按实际车体长度计算。

性能要求：开门预警只检查正在运行的路线附近有限轨段，按轨段 ticks 而非墙钟速度计算；不扫描整张地图。材质和静态轨道网格复用。保留已有存档 Def 名称和列车/货物引用。
