# 0.7 金属列车门、双轨模块与仓库自动货运需求

本轮在 0.6 单地图运营系统上实现，不依赖 DLC。玩家明确改变门的免费建设规则：单门消耗 40 单位金属、双轨门消耗 80；轨道、车站与仓库继续免费建设并保留工时。

| Use case | 游戏设计与验收 |
|---|---|
| 建造不同材质列车门 | 门进入“结构”，接受 Metallic 材料，使用原版 Stuff 的耐久、颜色、价值和开门速度计算；原版玻璃钢应比其他原版金属有更高最大耐久。不开设电力或研究要求。 |
| 旧免费门升级 | 缺少 Stuff 的已存门按钢材迁移，保留原对象与原生命值；不因新增成本补扣材料。 |
| 两条独立平行铁路 | 新增 3×3 可旋转双轨模块，轨道相隔一格；直线拖动批量建造，实际建筑格不重叠。两条轨不自动产生交叉连接；分别允许独立列车。 |
| 双线穿过同一道门 | 新增三格宽可旋转双轨门，两端为独立轨道，中间允许步行。继承原版门的开合、气密、寻路；任一列车或行人需要时整个门开合，保护两条线路车尾。 |
| 殖民者把资源送入货运仓库 | 新增双站台 5×5 及四站台 5×9 仓库，提供原版储存过滤器、优先级与搬运入口。仓库储存行与站台轨道行分离。 |
| 无需逐批手动装车 | 仓库可配置多个自动发货规则，明确路线、本站台、目的站台及货物类型。真实库存按规则顺序送入列车，八批容量，保留原物品与数量；无库存则不装货。 |
| 货运专列与客货两用列车 | 路线编辑器提供两种模式，默认客货两用。专列不接受自动乘客，其余线路、门、停站和颜色规则一致。 |
| 多站、多站台逐批卸货 | 每批固定目的站台，只在该站台卸货。不同目的地的货物留在车内，到各自站依次处理；先卸后装，每 30 ticks 处理一批。 |
| 目的仓库满了或拒收 | 不把货物丢到仓库外伪装成功。保留未卸部分，列车按停站规则继续运行，到下次访问再试；普通消息提示，不发暂停信件，同一路线与目的站台限频。 |
| 防止自动货运反复循环 | 默认已接收货物不自动再次发出；提供“转运接收货物”开关，由玩家主动启用有意中转。规则选择具体货物类型可分配多站目的地。 |
| 断轨、仓库拆毁、改线与读档 | 保存规则、库存过滤器、路线模式与车载物。延续旧系统安全恢复真实货物；拆仓库不删除库存；不复制、不吞货。 |

原版材质系数是默认标准；兼容其他 Mod 的 Metallic 材料，不保证第三方额外金属的耐久低于玻璃钢。双轨模块只提供平行直线，斜轨继续用单轨铺设。多站台货运不等于自动跨线路换乘；每条发货规则必须在同一运营路线内能到达目的站台。

性能：只在列车停站时检查所属仓库库存和发货规则，不逐 tick 扫全图资源或殖民者。消息限频且不改变时间速度。双轨格和门仍使用原拓扑缓存与静态轨道网格。
