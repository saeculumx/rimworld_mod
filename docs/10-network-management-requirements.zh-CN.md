# 0.5 路网管理、环线与多站台设计

用户要求：增加多站台车站；支持环线；独立管理标签页集中修改全部路线；路线颜色；停站时间手动输入并可启用自动管理；补足站台各轨道连接计算及相关交互。

## 运营与空间规则

- 建筑菜单提供 3×3 单站台、5×5 双站台、5×9 四站台。均东西向贯通，站台编号由南向北，轨道之间留一格步行/作业带。每条轨道有独立的停靠格、左右接入口、停站设置和连接状态。旧单格站继续读档。
- 多站台属于同一建筑，不把不同轨道自动连通。对每个站台分别从实际轨道格搜索其他站台；玩家可在站外铺轨连接或建立交叉。菜单显示实际可达目标、接入口和占用路线。
- 一条运营路线停靠 2–16 个不同的「车站＋站台」。往返路线到两端折返；环线必须闭合，按选择的正向或反向持续运行。闭合段与其余轨段一并检查，不能用去程原路回走冒充环线。
- 每条路线一辆常驻列车。不同路线可位于同一连通路网，但不能占用相同轨道格；配置时拒绝重叠，拆改导致重叠时暂停冲突路线。这允许相连但不重叠的线路、多站台并行服务，避免当前没有完整信号系统时发生对向死锁。暂停或故障车仍有实际占格，其他列车不能驶入。
- 整体路径每格只访问一次，环线首格不在路径末尾重复存储；最后一格通过闭合边回到首格。允许同一建筑的不同站台作为不同停站。

## 管理和可理解的交互

- 底部增加「轨道」主标签，内有「路线」「车站」页面。路线列表显示名称、颜色、运行类型、客货数量、候车人数与故障；支持创建、编辑、暂停/恢复、定位和撤销。
- 路线可以命名与选择颜色。地图路径、方向箭头和列车标识使用路线颜色，仍显示站序与名称，不能只依赖颜色区分。管理界面可显示全部路线，编辑时突出当前路线。
- 路线编辑停站时明确显示站台编号，可改站台、调整站序。候选项先检查实际连接并提供原因。确认再次验证全部路径及占用；取消不改变现有路线或站台设置。
- 路线编辑允许当前列车离开旧路径：释放乘客恢复原任务，保留原列车并移到新首站。保留仍在路线内的货物；已失去目的站台的货物安全放回。撤销有明确确认，暂停无需确认。
- 车站页面逐站台显示左右接轨、可达站台及占用路线，并提供定位、停站设置及货运目的地操作。

## 停站设置

- 手动模式使用游戏秒数字输入，支持小数，范围 0.5–120 秒；明确显示单位，提供常用时间快捷按钮，不使用滑块。无效/空白/超限数值阻止保存并说明原因。
- 自动模式默认最少 2 秒、最长 15 秒。下车先于上车，乘客按到站顺序每 15 ticks 上车一人，货物每 30 ticks 处理一批，活动后保留 1 秒安静期。
- 若有座位且已登记的乘客正在接近本站台，或同路线的装货工正在附近作业，则在最长等待内延长停站。等待估算有限，不扫描全图工人；满车不因候车队列无穷等待，满货仓也不为待装批次无限等待。
- 手动模式仍处理客货，但到设定时间发车。自动模式的最少/最长和手动秒数可分别输入，读档保留。对旧版本站台保留手动时间，避免迁移后自行改变行为。

## 扩展 Use cases / 验收

| 场景 | 验收要求 |
|---|---|
| 双站台的北线断轨 | 南线及另一条路线继续运行；连接表分别报告 |
| 车站楼相同但站台不同 | 接驳、候车、上下车和货物目标均使用准确站台 |
| 三站环线及反向环线 | 跨闭合边继续运行，不在末站折返；首站经过一次只停一次 |
| 环线上末站去首站 | 候车及车程按环向绕行计算，乘客和货物在首站正确到达 |
| 同网两条不重叠路线 | 均运行；路径重叠配置被拒绝，给出冲突路线 |
| 自动模式有赶来的乘客/装货工 | 延长停站，给上车/装卸留时间；最长期限仍会发车 |
| 手动时间输入错误或取消 | 不改原值；小数秒可保存，无滑块 |
| 从管理页改颜色/名称/站序 | 地图和列车标识更新，保存加载保留 |
| 暂停、拆站、改线、读档 | 不丢乘客和货物，路线引用与站台编号可恢复 |

实施：先建立站台和路线数据及迁移，再路径与环线时刻，随后客货调度、自动停站，最后管理页与编辑界面，进行实际引擎和图形验收。
