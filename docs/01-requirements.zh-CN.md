# 单地图轨道交通：需求基线

日期：2026-10-13。目标环境：本机 RimWorld 1.7.4977 rev926，Steam unstable，Waylith / .NET 10。

## 已由用户明确的要求

- 只在同一地图内运输 Pawn，解决长距离日常移动耗时。
- 首个 POC 必须自动调用轨道交通，不能仅靠手动乘车。
- 使用实体轨道，可见沿轨道移动的小型载具和乘客；允许简陋占位素材。
- 尽量少素材、少依赖。允许下载开发工具。
- 游戏路径为 `D:\SteamLibrary\steamapps\common\RimWorld`。
- 后续明确：部分产品化，优化性能并开发动画；初始设定不需要资源，生成香草艺术占位素材。

## POC 的具体设计假设

以下为可调整的实现基线，不代表用户逐条确认：

1. 玩家人类殖民者、非征召、未倒地；不自动运输动物、敌人、机甲、被搬运的 Pawn。
2. 1×1 地面轨道、1×1 车站；上下左右连接、双向运行、支持转角与分支。无跨地图、地下层、时刻表与实体列车车队。
3. 每次行程一人、一辆抽象小车。POC 不实现会车、信号、碰撞、车辆库存和运力限制。
4. 车站到车站乘坐，首版站点可位于轨道端点。沿途轨道必须连通且可通行，不允许穿墙或跨越无桥水面。
5. 自动交通优先覆盖原版基于寻路到达的日常工作/需求移动，保持原 Job 和目标；到站后继续原寻路。特殊 Mod 自定义移动需另行验证。
6. 距离至少 40 格才考虑，收益须至少 25% 且节省至少 120 ticks；候选接驳范围 24 格。列车每格 3 ticks，上下车合计 60 ticks。数值为可调 POC 初值。
7. 暂无材料成本、电力、燃料、研究、售票；轨道和车站仍由殖民者施工（60 / 300 WorkToBuild），也可用开发者模式放置。免费建筑的 MarketValue 为 0。轨道支持原生直线拖拽铺设，车站支持命名。
8. 首版不主动接管运货 Job；携带物品/另一 Pawn 时不自动乘车。允许 Pawn 自身装备与库存。
9. 行程中的乘客仍存在地图上，保留原版受伤、死亡、需求与选择语义；不放进容器，不销毁或复制 Pawn。

## 核心 use cases

| 场景 | 期望行为 | 验收方式 |
|---|---|---|
| 住宅区到远处农田/矿区 | Pawn 自行到站、沿轨道乘车、下车后继续原工作 | 100 格左右两端站点，观察原工作目标与完成状态 |
| 短途或明显绕路 | 继续步行 | 10 格任务、弯绕轨道任务 |
| 轨道不连通 | 不尝试乘车 | 拆掉中间一段再发起任务 |
| 轨道在行程中被拆除 | 在最后安全轨道格停止乘车，恢复步行或由原版处理不可达 | 运行时拆轨，检查 Pawn 仍在图上 |
| 目的站在行程中消失 | 取消乘车，恢复原目标寻路 | 运行时拆站 |
| 乘客被征召、倒地或更换工作 | 立即释放运输状态，不覆盖新命令 | 行程中征召/强制新工作 |
| 保存并读档 | 不产生失踪/重复 Pawn，能恢复原任务或重新寻路 | 上车前/行驶中/下车时各保存读档 |
| 多 Pawn、多地图 | 状态按 Pawn 和地图隔离，无全地图每 tick 扫描 | 10 人同时长距离移动，切换地图 |

## 成功标准与范围限制

POC 成功必须包括：对实际 1.7 程序集编译成功；路网与收益计算的可重复测试通过；实际游戏完成自动乘车与恢复工作、断轨/中断、存读档验收。编译或独立逻辑测试不能替代游戏内验收。

0.2 已加入显示插值、原创生成占位素材、站点与行程索引、有界拓扑缓存和规划预算；仍保守检查允许区域、危险路段和普通 Pawn 避让。后续加入更完整成本、队列与运力、货运和更多兼容。资源/电力平衡须等待新的需求，当前保持免费。
